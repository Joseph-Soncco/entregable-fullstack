# MangaCho

**MangaCho** Aplicación web para gestionar una tienda de mangas de anime **CRUD** con **Node.js**, **Express**, **EJS** y **MySQL**.

- 🎨 Registrar mangas con imagen  
- 🔍 Listar, buscar y filtrar por título, autor, categoría o género  
- ✏️ Editar datos y actualizar la imagen con vista previa  
- 🗑️ Eliminar mangas  
- 💾 Validación de precio máximo **S/. 300** (cliente, servidor y BD)

---

## 🚀 Tecnologías y dependencias

| Paquete      | Uso                               |
|--------------|-----------------------------------|
| express      | Servidor HTTP                     |
| ejs          | Motor de plantillas               |
| mysql2       | Cliente MySQL (promesas)          |
| body-parser  | Parseo de formularios             |
| multer       | Subida de imágenes (multipart)    |
| bootstrap 5  | Estilos UI (CDN)                  |

Instalación rápida:

```bash
npm install express ejs mysql2 body-parser multer
